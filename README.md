# emailsnatcher
Parses and returns all of the email addresses in HTML off of a webpage using Python.
This is useful for scraping email addresses off of webpages containing contact email addresses of Congress and Parliament members. If you know Python, you can add to the code to automate sending email to every email on the list. I know, I know, all I did was import a couple of libraries and define a function in order to parse through HTML for emails. That's the beauty and power of Python baby.
